# Ashburn Connected

**Local Places. Real Connections.**

Ashburn Connected is a local discovery platform focused on Ashburn, Virginia and the surrounding Northern Virginia community.

The project brings local businesses, restaurants, breweries, coffee shops, EV charging, travel information, and other community resources together in one place.

## Features

- 🍺 Local brewery discovery
- ☕ Coffee & Wi-Fi locations
- 🍽️ Restaurants
- ⚡ EV charging locations
- ✈️ IAD / Dulles travel information
- ⭐ Connected Score using Google ratings and review volume
- 🗺️ Interactive Google Maps integration
- 📍 Distance and location information
- 🏪 Local business discovery

## Technology

Ashburn Connected is currently built with:

- HTML
- CSS
- JavaScript
- Google Maps JavaScript API
- Google Places API
- AWS
- Amazon S3
- Amazon CloudFront

## Connected Score

The Connected Score is an experimental ranking system designed to provide additional context beyond a business's star rating alone.

It currently considers:

- Google star rating
- Number of Google reviews

This helps distinguish between a high rating based on only a few reviews and a strong rating supported by a larger history of customer feedback.

## Project Status

Ashburn Connected is actively being developed. New features, categories, and local resources will continue to be added as the project grows.
